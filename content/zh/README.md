# Chinese overrides

Put a file here only when an entry needs a Chinese-only version that differs from the bilingual one in `content/en/`.

Use the same relative path, for example `content/zh/afflictions/pneumothorax.md` overrides `content/en/afflictions/pneumothorax.md` on `/zh/afflictions/pneumothorax`. Entries without an override fall back to the `en` version.

This README is outside the type folders, so it isn't part of any collection.
